How to use the API


            
Basics

            
Base URL: /api/v1. Send the key in an Authorization: Bearer <key> header (or X-API-Key: <key>). Requests and responses are JSON; errors look like {"detail": "…"}. The website's rules still apply: blacklisted IPs are refused, and wrong share codes count toward the same per-IP limit.

            
接口地址：/api/v1。密钥放在请求头 Authorization: Bearer <密钥> 里（也可以用 X-API-Key: <密钥>）。请求和返回都是 JSON，出错时返回 {"detail": "…"}。网页上的规则同样适用：黑名单里的 IP 会被拒绝，提取码输错与网页共用同一个按 IP 计的次数限制。

            


export SHAREWEB_URL=
export SHAREWEB_KEY=swk_...
curl -H "Authorization: Bearer $SHAREWEB_KEY" $SHAREWEB_URL/api/v1/info


            
Endpoints

            

              
MethodPathDescription

              
                
GET/infoServer limits (max file size, max text size, retention days, max chunk size) and this key's name.服务器的限制（单文件上限、文本上限、保留天数、单块上限）和当前密钥的名称。

                
POST/filesUpload a file in one request (multipart/form-data, field file). Returns 201 and the share.一次性上传文件（multipart/form-data，字段名 file）。返回 201 和分享信息。

                
POST/uploadsStart or resume a resumable upload (recommended for large files, see below).开始或继续一个断点续传（大文件推荐，见下文）。

                
PUT/uploads/{upload_id}?offset=NSend the next chunk of a resumable upload.断点续传：发送下一块数据。

                
POST/textsShare text: {"text": "…"}. Returns 201 and the share.分享文字：{"text": "…"}。返回 201 和分享信息。

                
GET/sharesShares created with this key that are still valid, newest first. ?limit= 1–1000 (default 100), ?offset=.用这个密钥创建、仍然有效的分享，新的在前。?limit= 1–1000（默认 100），?offset= 分页。

                
GET/shares/{token}One share by its link token. Text shares include the text.按链接里的 token 查一个分享；文字分享会附上正文。

                
DELETE/shares/{token}Delete a share created with this key. Returns 204.删除用这个密钥创建的分享。返回 204。

                
GET/codes/{code}Find a share by its 4-digit code. Wrong codes count toward the per-IP limit, as on the website.按 4 位提取码查分享。输错的次数与网页一样按 IP 计入限制。

                
GET/llms.txtThis guide for AI agents, in Markdown (see "For AI agents / LLMs" above).给 AI agent 看的说明（Markdown，即上面「给 AI 看的版本」）。

                
GET/download/{token}Download the file. This is the share's download_url; it is not under /api/v1 and needs no key.下载文件，即分享里的 download_url。不在 /api/v1 下，不需要密钥。

Resumable upload (large files)

            
    
              
  1. Compute the file's SHA-256 and POST /uploads with {"sha256", "size", "filename"}. If the server already has the same file, the reply is {"exists": true, "share": {…}} and you're done.
    2. 
              
  2. Otherwise you get {"upload_id", "offset", "max_chunk"}. PUT the file's bytes starting at offset to /uploads/{upload_id}?offset=N, in chunks of up to max_chunk (8 MB is a good size). Each reply gives the new offset. After the last chunk the server checks the SHA-256 and replies {"done": true, "share": {…}}.
    3. 
              
  3. If the upload is interrupted, send the same POST /uploads again with "upload_id" added; the reply tells you where to continue. A 409 reply also contains the right offset. Unfinished uploads are kept for 24 hours and can only be continued with the key that started them.
    4. 
            

            
    
              
  1. 先算出文件的 SHA-256，POST /uploads，内容为 {"sha256", "size", "filename"}。服务器上已有相同文件时直接返回 {"exists": true, "share": {…}}，不用再传。
    2. 
              
  2. 否则返回 {"upload_id", "offset", "max_chunk"}。从 offset 处开始，把文件内容分块 PUT 到 /uploads/{upload_id}?offset=N，每块不超过 max_chunk（8 MB 比较合适）。每次返回新的 offset；最后一块收齐后服务器校验 SHA-256，返回 {"done": true, "share": {…}}。
    3. 
              
  3. 上传中断后，再发一次同样的 POST /uploads 并带上 "upload_id"，返回值告诉你从哪里继续。返回 409 时也会带上正确的 offset。未完成的上传保留 24 小时，只能用开始它的那个密钥继续。
    4. 
            

            
A complete Python example (needs pip install requests):
完整的 Python 示例（需要 pip install requests）：


import hashlib, os, sys, requests

API = os.environ["SHAREWEB_URL"] + "/api/v1"
H = {"Authorization": "Bearer " + os.environ["SHAREWEB_KEY"]}
CHUNK = 8 * 1024 * 1024

def upload(path, upload_id=None):
    sha = hashlib.sha256()
    with open(path, "rb") as f:
        for block in iter(lambda: f.read(1 << 20), b""):
            sha.update(block)
    r = requests.post(API + "/uploads", headers=H, json={
        "sha256": sha.hexdigest(), "size": os.path.getsize(path),
        "filename": os.path.basename(path), "upload_id": upload_id})
    r.raise_for_status()
    d = r.json()
    if d["exists"]:
        return d["share"]
    offset = d["offset"]
    with open(path, "rb") as f:
        while True:
            f.seek(offset)
            r = requests.put(f"{API}/uploads/{d['upload_id']}", headers=H,
                             params={"offset": offset}, data=f.read(CHUNK))
            if r.status_code == 409:      # server has a different offset: continue from there
                offset = r.json()["offset"]
                continue
            r.raise_for_status()
            step = r.json()
            if step["done"]:
                return step["share"]
            offset = step["offset"]

share = upload(sys.argv[1])
print(share["code"], share["url"])


            
Share fields

            

              
                
tokenID in the share link; use it with /shares/{token} and /download/{token}.分享链接里的 ID，用于 /shares/{token} 和 /download/{token}。

                
code4-digit share code.4 位提取码。

                
typefile or text.file（文件）或 text（文字）。

                
filename, size, sha256, mime_typeFile name, size in bytes, SHA-256, content type.文件名、大小（字节）、SHA-256、文件类型。

                
created_at, expires_atISO 8601 times in UTC. expires_at is null while the admin has locked the share.ISO 8601 格式的 UTC 时间。管理员锁定期间 expires_at 为 null（不过期）。

                
locked, download_countLocked by the admin (can't be deleted through the API); number of downloads.是否被管理员锁定（锁定的不能通过 API 删除）；下载次数。

                
url, download_urlShare page link; direct download link (files only, no key needed).分享页链接；文件直链（仅文件，不需要密钥）。

                
ownedCreated with this key. Only these appear in /shares and can be deleted. Uploading a file the server already has returns the existing share, which may not be yours.是否由当前密钥创建。只有这些会出现在 /shares 里、可以删除。上传服务器上已有的文件时会返回已有的那个分享，它可能不是你创建的。

                
textText shares only, returned by /shares/{token} and /codes/{code}.仅文字分享，在 /shares/{token} 和 /codes/{code} 中返回。

              
            


            
Status codes

            

              
                
200 201 204Success (201: created, 204: deleted).成功（201：已创建，204：已删除）。

                
400Malformed request or upload.请求或上传的数据格式不对。

                
401Missing, wrong or deleted API key.没带密钥、密钥错误或已被删除。

                
403Your IP is blacklisted.IP 在黑名单中。

                
404Not found, expired, not created by this key, or wrong code (the reply includes fail_count).不存在、已过期、不是这个密钥创建的，或提取码错误（返回中带 fail_count 已错次数）。

                
409Upload offset doesn't match (the reply includes the right offset), or the share is locked by the admin.上传的 offset 不对（返回中带正确的 offset），或分享已被管理员锁定。

                
413File, text or chunk too large.文件、文字或单块太大。

                
422Invalid parameters, or the uploaded data didn't match its SHA-256 (the upload is discarded; start over).参数不对，或上传的内容与 SHA-256 不符（这次上传作废，需重新开始）。

                
429Too many wrong codes; try again after cooldown_until.提取码错太多次，cooldown_until 之后再试。

                
507Not enough disk space on the server.服务器磁盘空间不足。
